# Paths and deterministic routing

Use `--` for straight segments and `|-` / `-|` for explicit orthogonal routing. Keep routing semantics (`straight`, `orthogonal`, `curve`, `loop`) separate from arrow direction and visual line style.

For academic diagrams, prefer simple routes with few bends. If a path crosses unrelated content, repair the layout or anchors before adding decorative routing complexity.

Source: PGF/TikZ 3.1.11a path syntax chapters. Example: `path-routing`.
