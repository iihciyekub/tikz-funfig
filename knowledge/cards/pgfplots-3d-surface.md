# PGFPlots 3D surfaces and meshes

Use `\addplot3` with `surf` or `mesh` for genuine two-input surfaces. Keep domain, sampling, view angle, shader, and color mapping explicit because each can materially change how structure is perceived.

Prefer a stable, publication-oriented view over dramatic perspective. Add a colorbar only when color encodes a quantitative variable.

Do not use 3D merely for decoration when a 2D representation communicates the data more accurately.
