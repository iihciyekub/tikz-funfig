# OpenTikZ curated source

Pinned, content-only snapshot of OpenTikZ used as community reference knowledge.

- Upstream: <https://github.com/opentikz/opentikz>
- Revision: `359befbf8e8af7ce08e7e387b2c2a198e0ca735d`
- Included: 9 templates, 3 paper-grade examples, their JSON metadata, catalog/schema, and license/readme files.
- Excluded: icons, brand marks, previews, website, build tooling, Skills, CI, and generated assets.
- Graphic content license: CC0-1.0.

Community content is never promoted directly to a stable TIKZ-FunFig Recipe.
It first enters the normalized community corpus and remains visibly lower-trust
than official PGF/PGFPlots source material and project-authored Templates.
