# Flowchart node shapes

Use restrained role-to-shape mapping: process/module -> rounded rectangle, decision -> diamond, terminal -> ellipse, data -> parallelogram. Shape should clarify role without decorative complexity.

Do not claim BPMN/UML conformance unless the requested notation is actually implemented.

Source: PGF/TikZ 3.1.11a shape libraries. Example: `flowchart-shapes`.
