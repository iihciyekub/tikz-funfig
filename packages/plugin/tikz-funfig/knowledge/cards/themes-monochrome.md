# Journal monochrome theme

In grayscale, preserve meaning with shape, line style, labels, grouping, and spacing. Use black/gray values with sufficient contrast; avoid distinctions that disappear when printed in black and white.

Theme changes may alter appearance tokens only. They must not change node IDs, edge endpoints, data, labels, or directionality.

Source: TIKZ-FunFig publication design rules. Example: `theme-monochrome`.
