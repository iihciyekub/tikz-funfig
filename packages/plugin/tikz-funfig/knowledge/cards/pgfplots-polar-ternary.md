# PGFPlots polar and ternary axes

Use the `polar` and `ternary` libraries only when the coordinate system matches the scientific meaning of the data. Polar axes represent angular/radial structure; ternary axes represent three-component compositions under the required normalization.

Keep coordinate conventions, angle units, and ternary component meanings explicit in labels and data bindings.

Do not convert ordinary Cartesian relationships into polar or ternary form for visual novelty.
