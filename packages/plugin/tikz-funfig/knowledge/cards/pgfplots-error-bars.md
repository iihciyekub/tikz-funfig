# PGFPlots error bars

Use PGFPlots error-bar semantics rather than drawing whiskers manually. Choose the direction, explicit/relative mode, and symmetric/asymmetric inputs from the actual uncertainty data.

For table data, bind uncertainty columns explicitly. Error bars encode supplied uncertainty; TIKZ-FunFig must not invent standard errors, confidence intervals, or confidence levels.

At publication size, check cap size, line weight, marker visibility, and overlap with dense series.
